# SPI Master–Slave Communication in Verilog

## Overview

This project implements **Serial Peripheral Interface (SPI)** communication between a **master** and a **slave** using Verilog HDL.
The design demonstrates **full-duplex data transfer**, where the master and slave exchange data simultaneously over MOSI and MISO lines.

The implementation includes:

* SPI Master module
* SPI Slave module
* Testbench for simulation and verification

The design follows a simple **FSM-based master controller** and supports **8-bit data transfer**.

---

## SPI Signals

| Signal  | Description                                     |
| ------- | ----------------------------------------------- |
| `SCLK`  | Serial clock generated by master                |
| `MOSI`  | Master Out Slave In (data from master to slave) |
| `MISO`  | Master In Slave Out (data from slave to master) |
| `SS_N`  | Slave Select (active low)                       |
| `START` | Initiates SPI transfer                          |
| `DONE`  | Indicates transfer completion                   |

## Design Description

### SPI Master

The master module performs the following operations:

1. Waits in **IDLE state** for the `start` signal.
2. Loads transmit data.
3. Activates the slave by pulling `SS_N` low.
4. Generates `SCLK`.
5. Sends data through **MOSI** and receives data through **MISO**.
6. Asserts `done` when transfer is complete.

FSM States:

* `IDLE`
* `LOAD`
* `TRANSFER`
* `COMPLETE`

---

### SPI Slave

The slave module:

* Receives clock (`SCLK`) from the master
* Reads incoming bits from `MOSI`
* Sends outgoing bits through `MISO`
* Stores received data in `slave_rx`
